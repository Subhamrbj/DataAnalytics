# Healthcare Analytics for Doctor Visits

## Project Overview
This project performs exploratory data analysis on healthcare data related to doctor visits.

The analysis studies the relationship between:
- Doctor visits
- Illness count
- Income
- Gender
- Reduced activity days
- Health status
- Private insurance
- Government health insurance
- Chronic conditions

## Dataset
- 5,190 records
- 13 columns
- No missing values

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Load and display the dataset
2. Display dataset information
3. Analyze illness counts
4. Analyze minimum, maximum and median income
5. Compare reduced activity days by gender
6. Check missing values
7. Analyze correlations
8. Analyze income vs doctor visits
9. Analyze illness based on gender
10. Analyze health insurance coverage
11. Visualize reduced activity days by gender

## Key Findings
- Most common illness count: 1 illness — 1,638 people
- Minimum income: 0.0
- Median income: 0.55
- Maximum income: 1.5
- Female reduced activity days: 2,636
- Male reduced activity days: 1,837
- Females affected by illness: 2,023
- Males affected by illness: 1,613
- Private insurance coverage: approximately 44.3%
