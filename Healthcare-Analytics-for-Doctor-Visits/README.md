# Healthcare Analytics for Doctor Visits

## Project Overview
This project performs exploratory data analysis on healthcare data related to doctor visits.

The objective is to study how factors such as illness count, income, gender, health status, insurance coverage, and chronic conditions are related to doctor visits and reduced activity days.

## Dataset
- 5,190 records
- 13 columns
- No missing values

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Loaded and explored the dataset
2. Displayed column information and data types
3. Analysed illness counts
4. Analysed minimum, maximum, and median income
5. Compared reduced activity days by gender
6. Checked for missing values
7. Analysed correlation between numerical variables
8. Studied income vs doctor visits
9. Analysed illness distribution by gender
10. Analysed private and government health insurance
11. Visualized reduced activity days by gender

## Key Findings
- Most common illness count: 1 illness
- 1,638 people have an illness count of 1
- Minimum income: 0.0
- Median income: 0.55
- Maximum income: 1.5
- Female reduced activity days: 2,636
- Male reduced activity days: 1,837
- Females affected by illness: 2,023
- Males affected by illness: 1,613
- Approximately 44.3% of patients have private health insurance
